# 词条编辑准则

每条数据包含：稳定 ID、英文名、中文名、白话定义、应用例子、常见误区。分类带一个官方或第一方延伸阅读链接。

- 一句话解释不要继续堆陌生术语，避免把营销描述写成公认技术定义。
- 例子应具体说明输入、操作或结果，避免“赋能”“颠覆”等抽象承诺。
- 商业词汇如 AI Native、AI Wrapper、Vibe Coding 应说明其行业用法，避免声称存在唯一标准。
- 机制、产品、商业模式分清楚；API 不等于收费模型服务，Git 不等于 GitHub。
- 对绝对化表述进行检查：低温度不保证事实正确、RAG 不保证零幻觉、开放权重不等于任意商用。
- 稳定 ID 一经发布尽量不改，以保留本地训练记录的关联。
- 避免复制第三方长段文字。修订专业事实时，在 PR 中给出官方来源和核对日期。

初版编辑日期：2026-10-20。当前为原创入门摘要，不是认证课程或术语标准。
