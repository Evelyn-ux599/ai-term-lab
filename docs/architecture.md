# 架构与取舍

## 边界

应用在浏览器本地运行，不部署后端，不使用 AI API、远程字体或分析服务。开发工具采用原生 JavaScript ES modules 和 Node 内置模块，避免为了单屏交互引入框架与依赖升级负担。静态构建只复制公开资源。

## 状态

`state` 包含版本、当前词条 ID、音效设置、当前 session 和完成记录。`session` 包含唯一 ID、词条、阶段、状态、剩余时间与截止时间。

```text
抽词 → 就绪 → 学习 running → 汇报 running → done
                  ↕              ↕
                paused         paused
```

阶段转换以原始截止时间为基准。休眠后一次跳过两阶段也只记录一次完成。`core.js` 不操作 DOM，方便直接测试。

存储加载时先检查版本、词条 ID、时间和枚举字段，损坏记录回到可用初始状态。存储异常只影响持久化，不阻塞当前体验。跨标签页采用 storage 事件同步，最后写入优先。

## 随机与动效

`crypto.getRandomValues` 配合拒绝采样，避免整数取模偏差。每个词每次独立等概率。结果在点击时决定并保存；动画只是展示抽取结果。轮动过程不改变抽选概率。

滚轮以 requestAnimationFrame 的时间戳计算位置；每跨过一个格位时合成一次短机械声。掉帧时不追补积压音效。减少动态效果时使用短过渡。

## 音频与无障碍

AudioContext 在用户交互后启用。噪声经过带通滤波形成机械声，正弦波构成阶段提示。不使用第三方音频素材。浏览器静音、后台限制和设备设置可能阻止声音；视觉状态独立工作。

按钮使用原生语义，焦点可见；滚轮动画对读屏隐藏，只在停稳后播报结果。计时数字不每秒向读屏播报，阶段变化使用 live region。

## 已知限制

- 完成计数不证明用户实际学习或汇报。
- 记录不跨设备，清理浏览器数据或更换来源后无法自动恢复。
- 系统时间大幅变更会影响截止时间；同时操作多个标签页不具备事务隔离。
- 术语资料为入门解释，分类参考链接不是每句话的逐条证据。
- 无后台推送，页面关闭或锁屏时不保证响铃。
