# 词间 · AI Term Lab

随机抽一个 AI 概念，用 **10 分钟学习 + 3 分钟表达**，把知识讲成自己的话。

一个不调用模型 API、不需要账号、无第三方运行依赖的静态网页。界面为中文，词条包含英文名称。适合个人学习、朋友互讲和小组热身。

## 功能

- 100 个 AI、产品、创业与开源概念：解释、真实场景例子、常见误区、分类延伸阅读。
- 机械滚轮抽选，使用浏览器安全随机源及拒绝采样，所有词等概率，允许连续重复。
- Web Audio 本地合成逐格机械声和阶段提示音；支持静音。
- 10 分钟学习结束后自动进入 3 分钟表达；暂停、继续、重新开始。
- 汇报阶段默认收起答案，保留四个表达提示，可主动展开答案。
- 当前进度、声音设置和完成记录保存在当前来源下的浏览器本地存储。
- 响应式布局、键盘操作、状态播报与减少动态效果偏好支持。

## 本地运行

需要 Node.js 22 或更新版本。不需要 `npm install`，项目没有第三方依赖。

```sh
git clone https://github.com/Evelyn-ux599/ai-term-lab.git
cd ai-term-lab
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。也可用任意静态 HTTP 服务器提供本目录；请勿用 `file://` 直接打开，因为页面使用 ES modules。

```sh
npm run check  # 语法检查、数据和逻辑测试
npm run build  # 生成 dist/，不下载依赖
```

## 部署

将 `dist/` 发布到任意支持 HTTPS 的静态托管。所有资源使用相对地址，可部署在子路径。

GitHub Actions 模板位于 [`docs/github-workflows/`](docs/github-workflows/)。将它们复制到 `.github/workflows/` 后，主分支会自动检查、构建并发布 Pages。首次启用时，在仓库 Settings → Pages 中选择 **GitHub Actions**，然后运行部署工作流。部署地址以 GitHub 返回结果为准。

GitHub Pages 及其他海外托管在不同网络的访问体验有差异。面向中国大陆用户时，请在目标网络及微信内置浏览器实测；也可迁移到其他静态托管。更换网址不会自动迁移浏览器里的训练记录。

## 保存与计时规则

- 本地存储键：`ai-term-lab:v1`。不会录音、上传训练记录、读取联系人或使用统计 SDK。
- 学习与汇报都采用截止时间计算，而不是累计定时器次数。未暂停时，切换标签页、刷新或关闭浏览器期间仍计时。
- 暂停后保存剩余毫秒；再次继续时建立新截止时间。
- 页面回到前台或重新打开后校正当前阶段。后台、锁屏或音频受限时，提示音不保证及时播放；不补播错过的声音。
- 计时完整走完一轮才记录完成；按轮次 ID 去重。完成记录代表计时完成，不代表学习质量评定。
- 多个同源标签页通过 storage 事件同步状态。极短时间内同时操作采用浏览器存储的最后写入结果，不提供数据库事务保证。
- 无痕模式、浏览器限制、存储空间不足时可能无法保存；页面会显示提示。清除网站数据会删除记录。记录不跨浏览器、设备或网站来源同步。
- 计时基于设备系统时间；主动更改系统时钟可能影响剩余时间。

## 项目结构

```text
index.html         页面语义与初始界面
src/
  styles.css       响应式视觉与减少动画适配
  terms.js         100 个原创编辑词条
  core.js          随机抽取、纯函数计时、存储校验
  audio.js         本地声音合成
  main.js          DOM 交互与持久化
tests/             数据与关键状态边界测试
scripts/           无依赖开发服务器与静态构建
docs/              内容准则与架构说明
.github/           Issue 与 PR 模板
docs/github-workflows/
                   可启用的 CI 与 Pages 工作流模板
```

## 修改词条

编辑 `src/terms.js`，保留已有稳定 ID，按组添加英文名、中文名、解释、例子和误区。详见 [内容准则](docs/content-guide.md)。如改变总词条数，请同步测试中的明确数量和 README 描述。
